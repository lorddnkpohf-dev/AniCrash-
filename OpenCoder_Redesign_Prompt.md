# 🎨 OpenCoder — Промт для редизайна (стиль DeepSeek / Kimi)

Референсы: приветственный экран DeepSeek (кит-логотип, "С возвращением") и верхняя панель + чипы Kimi (pill-селектор модели, плавающие подсказки над полем ввода). Общая идея — убрать все "коробки" и бордеры, сделать интерфейс воздушным, всё скруглено в pill (капсулы), фон чистый чёрный без карточек.

---

## 🧠 ГОТОВЫЙ ПРОМТ ДЛЯ ИИ (вставь целиком)

```
Сделай редизайн приложения OpenCoder (React Native / Expo, файлы в app/(tabs)/*.tsx) 
в стиле DeepSeek и Kimi — максимально воздушный, "бесшовный" UI без видимых рамок.

ФИЛОСОФИЯ:
- Полный отказ от border: 1px везде, где это не критично для читаемости.
  Разделение элементов — через разницу оттенков фона (surface чуть светлее 
  background), а не через обводку.
- Все интерактивные элементы — форма pill (borderRadius: 999 / "full"), 
  а не скруглённый прямоугольник (12–22px). Единственное исключение — 
  bubble-сообщения в чате (оставить крупный радиус 16–20px, это ок).
- Много воздуха: увеличить вертикальные отступы между блоками минимум на 20%.
- Ничего не "в коробке". Заголовки, приветствие, чипы — просто плавают 
  на чёрном фоне, без borderColor и без background у контейнеров, 
  где это не обязательно.

1. ВЕРХНЯЯ ПАНЕЛЬ (header, экран Workspace):
   - Слева: иконка меню (три линии, ☰) вместо текущего лого-квадрата с рамкой — 
     просто иконка без фона и без border.
   - По центру-слева: pill с названием текущей модели вместо жирного логотипа 
     "OpenCoder" — по образцу Kimi ("Kimi Быстрый" в одной капсуле: название 
     жирным + подпись обычным весом рядом). Тап открывает тот же модальный 
     выбор модели, что и сейчас.
   - Справа: одна круглая icon-button (например mute/notifications или 
     "новый чат" в виде "+"), без прямоугольной кнопки с текстом "Новый" — 
     заменить на круглую (44×44, borderRadius: 999) с одной иконкой "+".
   - Убрать subtitle "BUILD WITH INTENT" — либо оставить очень тонкой 
     строкой под pill модели, либо убрать вовсе.

2. ПУСТОЙ ЭКРАН / ПРИВЕТСТВИЕ (когда нет сообщений):
   - По центру экрана (не вверху): маленький логотип-иконка (48–64px) 
     БЕЗ рамки, БЕЗ фонового кружка — просто сама иконка, как кит у DeepSeek.
   - Под ней — одна строка приветствия обычным (не жирным 900) шрифтом, 
     светло-серым цветом, по центру: "С возвращением! С чего начнём?" 
     или динамическое приветствие с именем/моделью, как у Kimi 
     ("Привет, {имя}. Что сделаем сегодня?").
   - Убрать текущие suggestion-карточки с рамкой (styles.suggestion с border). 
     Вместо них — либо ничего (пусто, как у DeepSeek), либо горизонтальный 
     ряд лёгких pill-чипов без фона/рамки, просто с лёгкой заливкой 
     (surface на 8–10% непрозрачности), по примеру нижнего ряда чипов 
     Kimi ("Новый проект", "Слайды", ...).

3. ПАНЕЛЬ ВВОДА (composer):
   - Само поле ввода — ОДНА большая pill (borderRadius: 999) на всю ширину, 
     без видимого border (или borderWidth: 0, только заливка surface). 
   - Внутри этой pill слева — круглая кнопка "+" (для вложений/файлов), 
     справа — круглая кнопка микрофона/отправки, обе borderRadius: 999, 
     как в макетах DeepSeek/Kimi (иконки встроены прямо в капсулу поля 
     ввода, а не отдельным блоком сверху).
   - Toolbar с иконками (skills / terminal / file), который сейчас стоит 
     отдельной строкой над полем ввода — превратить в ряд pill-чипов 
     с иконкой + коротким лейблом (как "🧩 Рассуждение" / "🌐 Поиск" 
     у DeepSeek): активный чип (например включённый skill) получает 
     заливку primary-цветом и белый/чёрный текст, неактивный — просто 
     тонкая pill без рамки на surface-фоне.
   - Селектор модели переносится из toolbar в pill в шапке (см. пункт 1) 
     — из composer убрать.
   - Убрать текстовую подпись "OpenRouter · free models" под полем ввода, 
     либо сделать её едва заметной (opacity 0.4, без отдельного блока).

4. СООБЩЕНИЯ В ЧАТЕ:
   - У ответа ИИ убрать borderWidth/borderColor у bubble — оставить только 
     заливку surface, что даёт эффект "плавающего" сообщения без контура.
   - Аватар ИИ (кружок с иконкой sparkles) — убрать border, оставить 
     просто мягкую заливку primary на 10-15% прозрачности.
   - Кнопку "Копировать" под ответом сделать иконкой без подписи текстом 
     (только иконка), либо мелким текстом без верхней линии-разделителя 
     (убрать borderTopWidth).

5. МОДАЛЬНЫЕ ОКНА (выбор модели, skills):
   - Убрать border у самого sheet (нижней шторки) — только заливка 
     surface с лёгкой тенью (shadow), без borderColor.
   - Строки списка (модель / skill) — убрать border у иконки-контейнера 
     слева, оставить просто мягкую заливку без обводки.

6. НИЖНИЙ TAB BAR:
   - Оставить плавающую капсулу как есть (уже в нужном стиле), но убрать 
     border-top у неё, если он выделяется на фоне.

7. ЦВЕТА И ТЕМА:
   - Тема остаётся чёрно-белой минималистичной (используй существующие 
     токены из theme.config.js — ничего нового не добавляй).
   - Единственный акцентный элемент — активные pill (выбранная модель, 
     включённый skill, отправка сообщения) — заливка цветом primary.

8. ЧЕГО НЕ ТРОГАТЬ:
   - Логику (opencoder-store, terminal-bridge, API-вызовы) не менять.
   - Анимации (Reanimated: fade/slide входа сообщений, typing-dots, 
     pulse-dot, breathing) — сохранить, только адаптировать под новые 
     формы (pill вместо прямоугольников).
   - Named-функциональность (skills, terminal, file attach) сохраняется 
     полностью — меняется только форма, не поведение.

Пройдись по всем экранам (index.tsx, history.tsx, settings.tsx, terminal.tsx) 
и приведи их к единому pill-стилю по этим правилам. В конце — краткий список 
того, что изменено, без лишних пояснений.
```

## 📱 Ключевые визуальные отличия (шпаргалка)

| Элемент | Сейчас в OpenCoder | Нужно (DeepSeek/Kimi) |
|---|---|---|
| Поле ввода | Прямоугольник, border 1px, radius 18 | Полная pill, без border |
| Кнопка "Новый чат" | Прямоугольная с текстом | Круглая иконка-кнопка |
| Логотип в шапке | Квадрат с рамкой | Просто иконка, без рамки |
| Селектор модели | Отдельный чип в toolbar | Pill в шапке рядом с меню |
| Toolbar (skills/terminal/file) | Голые иконки в ряд | Pill-чипы с лейблом |
| Приветствие | Карточка с рамкой + подсказки-кнопки с border | Просто текст по центру, без рамок |
| Bubble ответа ИИ | С border 1px | Без border, только заливка |
| Модалки | Border у sheet и у иконок строк | Без border, только тень |
